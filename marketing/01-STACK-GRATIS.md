# 01 · Stack GRATIS — qué instalar y activar

Todo lo de esta lista tiene **plan gratuito real** suficiente para arrancar. Empieza con el
"stack mínimo" y no instales más hasta que lo necesites: cada herramienta extra es tiempo
de mantenimiento.

## Conceptos en 3 frases
- **MCP (Model Context Protocol):** un "enchufe" que le da a Claude **manos dentro de otra app**
  (Canva, Gmail, Calendar). Le pides en lenguaje normal "diseña este carrusel" y lo ejecuta.
- **Skill de Claude:** un "mini-experto" que Claude invoca para una tarea (diseño, investigación).
- **Skills externos / plugins:** habilidades de terceros (`npx skills add ...`). **No urgentes.**

## 🔌 MCP a activar en Claude (gratis con tu login)

Se activan desde la configuración de **conectores / MCP** de Claude. No copias claves
técnicas: es un "Iniciar sesión con…" normal.

**Prioridad alta (actívalos ya):**
- **Canva** — diseña y exporta carruseles/posts con tu marca desde un prompt.
- **Gamma** — genera lead magnets y mini-guías descargables (tiene plan free).
- **Gmail** — redacta borradores de nurturing y respuestas a leads en tu voz.
- **Google Calendar** — crea eventos de diagnóstico y propone horarios.

**Prioridad media (al escalar):**
- **Google Drive** — repositorio central de plantillas y lead magnets.
- **Supermetrics** — trae métricas de IG para reportes automáticos (tiene capa free limitada).

**Bonus de autoridad (para CONTENIDO, nunca datos de clientes):**
- **PubMed** y **Consensus** — generas posts respaldados en papers reales. Te diferencia de
  la competencia genérica. *Tú ya tienes PaperFlow AI haciendo esto internamente.*

## 🧠 Skills GRATIS de Claude que ya puedes usar

Estas vienen incorporadas en Claude Code / Claude.ai. No "se descargan": se invocan.

- **`deep-research`** — investigación multi-fuente verificada y con citas. Úsala para
  preparar contenido educativo sólido o estudiar a la competencia/audiencia.
- **Diseño visual / export a Adobe Express** — Claude crea piezas gráficas y las exporta a
  un editor. Útil para plantillas de carrusel.
- **`code-review` / `simplify`** — para tu producto PaperFlow AI (calidad de código gratis).

**Skills externos / plugins (`npx skills add ...`):** son de terceros y se instalan como
paquetes. **No los necesitas todavía.** Tu prioridad son los MCP de diseño, correo y
calendario. Considera un plugin externo solo cuando un flujo concreto lo pida (ej. video
programático). Regla: exprime primero lo incorporado + MCP.
